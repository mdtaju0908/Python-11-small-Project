# 🎬 Movie Ticket Checker

A simple Streamlit application that checks if a user is eligible to watch a movie and enter the theater based on their age and ticket possession.

## 🛠️ Installation

1. Install the required packages:
   ```bash
   pip install -r requirements.txt
   ```

## 🚀 How to Use

1. Run the Streamlit app:
   ```bash
   streamlit run ticket.py
   ```
2. Enter your **Age**.
3. Check the box if you have a **Ticket**.
4. Click **Check Eligibility** to see the result.
