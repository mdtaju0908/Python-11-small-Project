# 🧮 Smart Calculator

A versatile calculator app built with Streamlit that supports basic arithmetic operations and common unit conversions.

## 🛠️ Installation

1. Install the required packages:
   ```bash
   pip install -r requirements.txt
   ```

## 🚀 How to Use

1. Run the Streamlit app:
   ```bash
   streamlit run calculator.py
   ```
2. Use the **Basic Calculator** tab for:
   - Addition, Subtraction, Multiplication, and Division.
3. Use the **Conversions** tab for:
   - Temperature (Celsius to Fahrenheit).
   - Length (KM to Meter).
   - Weight (KG to Pounds).
