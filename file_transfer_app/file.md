# 📁 File Transfer App

A simple file management application built with Streamlit that allows you to upload and download files locally.

## 🛠️ Installation

1. Install the required packages:
   ```bash
   pip install -r requirements.txt
   ```

## 🚀 How to Use

1. Run the Streamlit app:
   ```bash
   streamlit run file.py
   ```
2. **Upload Section**: Choose a file from your computer to upload it to the `uploads` folder.
3. **Download Section**: Click on any file in the list to download it back to your computer.
