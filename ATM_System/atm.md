# 🏧 ATM Pin System

A simple ATM simulator built with Streamlit that allows users to check balance, withdraw money, and deposit money after PIN verification.

## 🛠️ Installation

1. Install the required packages:
   ```bash
   pip install -r requirements.txt
   ```

## 🚀 How to Use

1. Run the Streamlit app:
   ```bash
   streamlit run atm.py
   ```
2. Use the default PIN: `2121` to log in.
3. Once verified, you can:
   - Check your current balance.
   - Withdraw money (updates balance).
   - Deposit money (updates balance).
   - Exit the system.
