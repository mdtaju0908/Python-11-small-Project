# 💬 WhatsApp Message Sender

An automation tool built with Streamlit and `pywhatkit` to send WhatsApp messages instantly to any phone number.

## 🛠️ Installation

1. Install the required packages:
   ```bash
   pip install -r requirements.txt
   ```

## 🚀 How to Use

1. Run the Streamlit app:
   ```bash
   streamlit run app.py
   ```
2. Enter the **Phone Number** (with country code, e.g., +91...).
3. Type your **Message**.
4. Click **Send Message**.
5. The app will open WhatsApp Web in your browser and send the message automatically after a short delay.
   *Note: Ensure you are logged into WhatsApp Web on your default browser.*
