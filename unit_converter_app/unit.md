# 🔄 Unit Converter

A versatile and easy-to-use unit conversion tool built with Streamlit. It supports various conversions across Length, Weight, and Temperature categories.

## 🛠️ Installation

1. Install the required packages:
   ```bash
   pip install -r requirements.txt
   ```

## 🚀 How to Use

1. Run the Streamlit app:
   ```bash
   streamlit run unit.py
   ```
2. Select a **Category** (Length, Weight, or Temperature).
3. Enter the **Value** you wish to convert.
4. Choose the specific **Conversion** (e.g., Meter → Kilometer).
5. Click **Convert** to see the result.
