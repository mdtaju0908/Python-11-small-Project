# 🌐 Simple Web App

A basic multi-page web application built using Streamlit, featuring a navigation sidebar and simple pages.

## 🛠️ Installation

1. Install the required packages:
   ```bash
   pip install -r requirements.txt
   ```

## 🚀 How to Use

1. Run the Streamlit app:
   ```bash
   streamlit run api.py
   ```
2. Use the **Sidebar Navigation** to switch between the **Home** and **About** pages.
3. Interact with the content and buttons on each page.
