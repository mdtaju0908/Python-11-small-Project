# 🎤 Text to Speech App

A dual-purpose Streamlit app that converts text into audible speech and can execute simple system commands like opening Notepad.

## 🛠️ Installation

1. Install the required packages:
   ```bash
   pip install -r requirements.txt
   ```

## 🚀 How to Use

1. Run the Streamlit app:
   ```bash
   streamlit run tts.py
   ```
2. **Text to Speech**:
   - Enter text in the text area.
   - Click the **🔊 Speak** button to hear it.
3. **Command Executor**:
   - Enter a command (e.g., "open notepad").
   - Click **Run Command** to execute it on your system.
