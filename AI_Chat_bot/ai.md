# 🤖 AI Chatbot

A simple AI chatbot powered by Google's Gemini API and built with Streamlit.

## 🛠️ Installation

1. Install the required packages:
   ```bash
   pip install -r requirements.txt
   ```

## ⚙️ Setup

1. Create a `.env` file in the `AI_Chat_bot` directory.
2. Add your Google Gemini API Key to the `.env` file:
   ```env
   GEMINI_API_KEY=your_api_key_here
   ```

## 🚀 How to Use

1. Run the Streamlit app:
   ```bash
   streamlit run ai.py
   ```
2. Enter your question in the text input and click **Send**.
3. The chatbot will respond using the Gemini AI model.
